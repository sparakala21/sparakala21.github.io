Spotify Artist Network Dataset

Data Analytics · python+networkx · NLP

Built a social network connecting artists based on Spotify recommendation co-occurrence.

The project started by crawling recommendation paths. I scraped data from artist profile pages to build a behavioral co-occurrence graph.

The dataset revealed dense communities and unexpected bridges between genres. I used node2vec for embeddings and projected them using T-SNE and UMAP into 3D space.
